# End-to-End-E-Commerce-Analytics-Dashboard
This project presents a comprehensive E-Commerce Business Intelligence Dashboard built in Power BI, offering a 360° analytical view of revenue, customers, products, orders, and global sales distribution. The dashboard consolidates multiple insights, enabling executives and business teams to make precise, data-driven decisions.

🚀 Project Overview

The dashboard analyzes multi-year e-commerce sales data and delivers insights across:

🌍 Global Orders & Country-level Performance

🛍️ Product Insights: Revenue, Orders, Profit & Returns

👥 Customer Segmentation & Revenue Contribution

📈 Revenue Trends, Forecasting & Monthly KPIs

🔍 Top Products, Top Customers & Category-Wise Breakdown

The report consists of the following major pages:

- Executive Dashboard – High-level KPIs, monthly trends & revenue forecasting

- Product Details – Product-level performance, targets, returns & metrics

- Customer Details – Demographics, income, occupation & customer ranking

- Map View – Global order distribution visualized on a geographic map

🛠️ Tools & Technologies Used
  Tool	         Purpose
- Power BI:-	    Dashboard building & visualization
- Power Query:-  	Data cleaning and transformation
- DAX:-         	KPI calculations, forecasting, performance metrics
- Excel / CSV:-	  Source data
- Map Visuals:-	  Geospatial insights
  
🗂️ Data Model Overview

- Star schema design with the following:

- Fact Table: Orders

- Dimensions: Customer, Product, Country, Date

- Key DAX measures include:

- Total Revenue

- Total Orders

- Total Profit

- Revenue Per Customer

- Return Percentage

- Forecasted Revenue

📌 Key Insights

- Subscribed customers deliver significantly higher revenue.

- Water Bottle (30 oz.) is a top-performing product with 7967 orders.

- USA, UK, and Australia dominate global order contribution.

- Revenue shows strong upward trend with seasonal fluctuations.

- Skilled manual and professional customers form the largest revenue segments.
